# CTU Naga Extension Campus Information Website

A React-based redesign of the campus information website for Cebu Technological University – Naga Extension Campus.

## Stack

- React 19 + Vite
- Three.js for a lightweight 3D orbital hero scene
- GSAP + ScrollTrigger for page and scroll-reveal motion
- Vitest + Testing Library for component-level acceptance tests

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run build
```

## Project notes

- The original CTU seal in `assets/ctu-logo.png` is retained.
- Campus history, contact details, program counts, news, and service links are based on the official CTU Naga website.
- Official campus photographs are loaded from CTU's public website.
- Event links point to official campus calendar and activity pages. No unverified event dates are invented.
- This is a student website concept and is not an official CTU publication.
